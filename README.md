mend is one command-line tool that applies AI-written edits in all four formats — unified diffs (even with wrong line numbers), SEARCH/REPLACE blocks, V4A patches and JSON editor tool calls — to a tree of text files. It finds the lines each edit names even when whitespace or indentation drifted, and changes every file or none.

## Run it

```sh
node main.ts [options] [PATCH]
```
